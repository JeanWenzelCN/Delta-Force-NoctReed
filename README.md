# NoctReed

守夜人口琴（Vigil Harmonica）自动演奏工具，通过 Android 无障碍服务模拟手势点击游戏内按键。

## 工作原理

1. **简谱解析**：内置解析器支持数字简谱，识别高低音点、升降号（# / b）、延音线（-）、乐句分隔（|）与换行。
2. **无障碍手势注入**：利用 `AccessibilityService.dispatchGesture()` 在屏幕上模拟点击，按校准坐标逐个触发游戏内按键。
3. **音区与半音切换**：演奏前自动切换到目标音区（低音 / 中音 / 高音），半音按键独立切换。
4. **BPM 实时调速**：BPM 保存在状态总线（StateFlow），悬浮窗加减按钮实时修改，播放循环每个事件都重新读取当前值。

## 功能

- 粘贴数字简谱直接演奏
- 导入 .txt 乐谱 / .mid 单旋律 MIDI 文件（自动转简谱 + 提取 BPM）
- 乐谱库：保存 / 重命名 / 删除 / 切换，随曲保存 BPM
- 悬浮窗控制：播放 / 暂停 / 停止 / 切换乐谱 / 校准 / BPM 调速，可折叠可拖动
- 引导式按键校准：按提示依次点击 12 个键位（8 音符 + 4 调性），坐标存入 SharedPreferences
- Material You（莫奈取色）浅色主题

## 使用步骤

1. 安装 APK，打开应用
2. 开启**无障碍服务**（设置 → 无障碍 → NoctReed）
3. 授权**悬浮窗权限**（允许显示在其他应用上层）
4. 进入游戏守夜人口琴界面
5. 点悬浮窗上的**校准**，按提示点击游戏内按键（共 12 个）
6. 粘贴或载入乐谱，点**开始**

## MIDI 导入要求

- 单旋律，无和弦（多个同时发音的音符只取最高音）
- 音域在低音 5 ～ 高音 1 之间
- 自动检测 BPM 并写入

## 构建

```bash
./gradlew assembleRelease
```

CI 构建见 GitHub Actions，签名密钥通过 Repository Secrets 注入。

|------|------|
| 无障碍服务 | 模拟手势点击游戏按键 |
| 悬浮窗 | 在游戏上层显示控制面板 |
| 前台服务 | 保持悬浮窗服务存活 |
